# Upstream submission

Use the [proposal](PULL_REQUEST.md) for the concrete source/destination mapping. Fork the target upstream repository, branch from its chosen release and copy the mapped theme/contribution files. Include the actual integration changes to packaging or the VOIZ theme-install stage. Do not upload the entire standalone repository over upstream.

Open a draft PR with the proposal and an accurate record of the owner's evaluation. No tests were run for this revision. Keep existing theme assets available during migration and let maintainers decide when to change defaults. The prepared documents do not constitute an upstream submission or acceptance.
