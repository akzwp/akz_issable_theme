# AKZ Persian theme

This package's beginner guides are written in Persian:

1. [Start here](README.md): choose installation, updating or uninstallation.
2. [Install](INSTALL.md): connect to the server, download the complete Persian package and install it.
3. [Update](UPDATE.md): obtain new files before rerunning the installer.
4. [Uninstall](UNINSTALL.md): restore the previous selection while retaining recovery files.

For the English edition and its English guides, open the [en branch](https://github.com/akzwp/akz_issable_theme/tree/en). Its installed theme is `akz`; this Persian package installs `akzfa`. Do not substitute the English package when updating the Persian theme.
