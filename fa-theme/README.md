# پوستهٔ فارسی AKZ برای ایزابل و VOIZ

AKZ رابط فارسی و راست‌چین یک سرور ایزابلِ از قبل نصب‌شده است. نام فنی این پوسته روی سرور `akzfa` است. حالت روشن و تیره، منوی واکنش‌گرا، جست‌وجوی بخش‌ها و ظاهر هماهنگ فرم‌ها، جدول‌ها و تقویم از امکانات آن هستند.

**اگر تجربهٔ نصب روی سرور ندارید، از [راهنمای نصب گام‌به‌گام](INSTALL.md) شروع کنید.** در آن راهنما، محل اجرای هر فرمان و نتیجهٔ مورد انتظار توضیح داده شده است. سرور برای نصب به Node.js، npm یا ساخت CSS نیاز ندارد.

## ۱. راهنمای مناسب کارتان را انتخاب کنید

## ۲. بدانید فرمان‌ها را کجا اجرا کنید

1. از رایانهٔ شخصی فقط برای اتصال SSH یا دریافت بسته و انتقال آن استفاده کنید.
2. فرمان‌های لینوکسی نصب را **پس از اتصال، روی خود سرور ایزابل** اجرا کنید.
3. بستهٔ فارسی را کامل دریافت کنید؛ کپی‌کردن تنها install.sh، یک فایل CSS یا فقط پوشهٔ پوسته کافی نیست.
4. وارد پوشه‌ای شوید که `README.md`، `VERSION`، `install.sh`، `uninstall.sh`، `framework` و `contrib` را کنار هم دارد.
5. مراحل راهنمای مربوط به کارتان را به‌ترتیب انجام دهید.

بستهٔ شاخهٔ `fa` پس از استخراج، پوشهٔ `akz_issable_theme-fa` را می‌سازد. اگر شاخهٔ `main` را دریافت کرده‌اید، باید وارد زیرپوشهٔ `fa-theme` آن شوید. داخل بستهٔ مستقل شاخهٔ fa، زیرپوشهٔ دیگری به نام fa-theme وجود ندارد.

## ۳. ترتیب نصب اولیه

1. اتصال SSH، دسترسی root و پیش‌نیازها را طبق [مراحل ۱ و ۲ راهنمای نصب](INSTALL.md) آماده کنید.
2. طبق مرحلهٔ دریافت بسته در همان راهنما، نسخهٔ کامل فارسی را بگیرید.
3. مقدار VERSION و مسیر پوشه را یادداشت کنید و در محیط root فرمان `bash install.sh` را اجرا کنید.
4. منتظر پیام شروع‌شونده با `Installed akzfa, version` بمانید و مسیر بازیابی چاپ‌شده را ذخیره کنید.
5. از رابط وب ایزابل خارج و دوباره وارد شوید؛ انتخاب پوسته را طبق راهنما بررسی کنید.

نصب‌کننده به‌صورت پیش‌فرض پوسته و زبان فارسی را انتخاب می‌کند. زبان فارسی باید از قبل روی سرور موجود باشد. گزینهٔ `--no-activate` برای نصب فایل‌ها بدون تغییر انتخاب فعلی است و در راهنمای نصب جداگانه توضیح داده شده است.

## ۴. ترتیب به‌روزرسانی

1. یک بستهٔ جدید بگیرید، یا نسخهٔ Git را طبق [راهنمای به‌روزرسانی](UPDATE.md) به‌روز کنید.
2. نصب‌کننده را **از همان بستهٔ جدید** اجرا کنید.
3. نسخهٔ چاپ‌شده و مسیر بازیابی را ذخیره کنید.
4. از ایزابل خارج و دوباره وارد شوید.

حذف قبل از ارتقا لازم نیست. نصب دوباره از پوشهٔ قدیمی، تغییرات GitHub را دریافت نمی‌کند. فرمان `cat VERSION` نیز فقط نسخهٔ بستهٔ داخل همان پوشه را نشان می‌دهد؛ به‌تنهایی اثبات نمی‌کند که آن نسخه روی سرور نصب شده است.

## ۵. ترتیب حذف و بازگردانی

1. [راهنمای حذف](UNINSTALL.md) را باز کنید و نام پوستهٔ قبلیِ ذخیره‌شده را بخوانید.
2. وارد پوشهٔ یک بستهٔ کامل فارسی روی سرور شوید.
3. در محیط root فرمان `bash uninstall.sh` را اجرا کنید.
4. از رابط وب خارج و دوباره وارد شوید.

این فرمان فقط وقتی akzfa هنوز فعال باشد، انتخاب قبلی را بازمی‌گرداند. فایل‌های پوسته و سوابق بازیابی باقی می‌مانند. حذف در این مخزن به معنی پاک‌کردن ایزابل، اطلاعات تماس یا بازگرداندن فایل‌های نسخهٔ قدیمی AKZ نیست.

## اصلاحات نسخهٔ ۲.۰.۱

- انتقال اصلاحات محلیِ آیکون‌ها و تقویم از CSS نهایی به سورس قابل نگهداری.
- اصلاح ظاهر کلید Issabel Network بدون جابه‌جایی ثابت وابسته به اندازهٔ صفحه.
- سازگاری با کلاس‌های موجود در قالب ماژول‌های VOIZ.
- نشانی نسخه‌دار فایل‌های CSS/JS و تازه‌کردن زمان فایل‌های نصب‌شده برای کاهش مشکل نمایش نسخهٔ قدیمی.

## سورس، مشارکت و وضعیت ارزیابی

منبع اصلی در [main/fa-theme](https://github.com/akzwp/akz_issable_theme/tree/main/fa-theme) نگهداری می‌شود و شاخهٔ fa بستهٔ آمادهٔ نصب آن است. [معماری](ARCHITECTURE.md)، [راهنمای توسعه](contrib/akzfa-theme/README.md) و [پیشنهاد مشارکت بالادستی](PULL_REQUEST.md) برای توسعه‌دهندگان هستند و مطالعهٔ آن‌ها برای نصب لازم نیست.

هیچ آزمون مرورگر، نصب یا آزمون خودکار برای این تغییرات اجرا نشده است. [وضعیت سازگاری](COMPATIBILITY.md) را ببینید؛ ارزیابی روی سرور بر عهدهٔ مالک است. نمایش محلی با داده‌های نمونه، تأیید رفتار همهٔ ماژول‌های واقعی نیست.

[مجوز](LICENSE)، سرصفحه‌های اصلی و [اطلاعیهٔ اجزای ثالث](contrib/akzfa-theme/THIRD_PARTY_NOTICES.md) باید حفظ شوند. نام AKZ به معنی تأیید رسمی Issabel یا VOIZ نیست.
