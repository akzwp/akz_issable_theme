# Issabel AKZ Persian Theme (akzfa)

A professional, right-to-left Persian theme for the Issabel web panel — dark/light modes,
Vazirmatn font, live module search, responsive layout. Theme-only; no core files are overwritten.

See [README.md](README.md) (Persian) for installation and [ARCHITECTURE.md](ARCHITECTURE.md) for the
technical design. License: GPL-2.0-or-later; Vazirmatn font: SIL OFL 1.1.

Quick install on an existing Issabel server:

```bash
sudo bash fa-theme/contrib/akzfa-theme/install.sh --activate
```
